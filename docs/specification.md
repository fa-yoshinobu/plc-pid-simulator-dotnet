# PLC PID プロセスシミュレータ 仕様書

アプリの動作と設定を記載する。操作手順は [使い方](usage.md)、変更履歴は [CHANGELOG.md](../CHANGELOG.md) を参照。

## 1. 目的

PLC上のPIDコントローラの動作確認・調整用Windowsアプリケーション。PLCからMV（操作量）を受信し、選択された仮想制御対象の動特性を計算してPV（プロセス値）をPLCへ返す。複数の制御対象を登録し、同時に実行できる。

実装環境：C# / .NET 9、WPF（Windows 10 / 11）。

## 2. 基本コンセプト

- 起動時は制御対象0件の空の新規プロジェクトを表示する。「ファイル → DEMOを開く」で同梱の DEMO.psim（全15種類を1件ずつ、ダミーPLC）を停止状態で読み込む。
- 制御対象がないときは空画面を表示し、「① 通信設定 → ② 制御対象を登録」の順に案内する。「プロジェクトを開く」も選べる。
- 「登録」から制御対象を追加する。
- 登録対象はカード形式で一覧表示する。
- カード選択で対象の詳細画面を開く。
- 詳細画面から開始・停止、グラフ、モデルパラメータ、強制値、外乱などを操作する。
- PLC通信とプロセスモデルを分離し、モデル追加や通信方式変更を容易にする。
- 複数の制御対象を同時にシミュレーションできる。

## 3. システム構成

``` text
PLC
 ├─ SP
 ├─ PID → MV ─────────────→ Simulator
 │                           ↓
 │                     Process Model
 │                           ↓
 └──────── PV ←──────────────┘
```

シミュレータ内部は次のように分離する。

| 層 | プロジェクト | 内容 |
| --- | --- | --- |
| モデル演算・制御対象管理・トレンド・ログ・設定保存 | `PidSimulator.Core` | 画面と通信方式に依存しない |
| PLC通信（SLMP） | `PidSimulator.Plc.Slmp` | PlcComm.Slmp を使用 |
| PLC通信（Host Link） | `PidSimulator.Plc.HostLink` | PlcComm.KvHostLink を使用 |
| PLC通信（Modbus TCP） | `PidSimulator.Plc.Modbus` | AMWD.Protocols.Modbus.Tcp を使用 |
| GUI | `PidSimulator.App` | WPF（MVVM） |

PLC通信は `IPlcClient` で抽象化する。

- `DummyPlc`：PLCなしで動作確認するためのダミーPLC。レジスタを保持し、PLC側のPI制御またはリレーON/OFF制御を模擬する。
- `SlmpPlcClient`：MELSEC SLMP（バイナリ 3E/4E、TCP/UDP）。
- `HostLinkPlcClient`：KEYENCE KV Host Link（TCP/UDP）。
- `ModbusPlcClient`：Modbus TCPのClient（マスター）。PLC・リモートI/OのServer（スレーブ）へ接続する。

## 4. メイン画面

制御対象ごとのカードを並べる。制御対象がないときは §2 の空画面を表示する。

カード表示項目：

- 計装タグ（名称先頭の `LIC-101` などを円＋水平線の記号で表示）
- 制御名称、モデル種類、説明
- 状態（停止 / 制御中 / プレビュー / 異常）と FORCE 表示
- SP / PV / MV（工業値）と直近2分のミニトレンド
- PLC通信状態
- PV書込先アドレス、MV読込アドレス、演算周期

カード選択で制御詳細画面へ遷移する。カードのメニューから、登録内容編集・複製・削除ができる。

## 5. 制御対象登録

登録ウィザード（6ステップ）で行う。編集・複製も同じ画面を使う。

1. モデル選択
2. 基本設定
3. レンジ設定
4. PLC通信設定（設定済みのレンジで接続テスト）
5. 初期値・停止時・異常時の動作
6. 確認（設定チェック）

### 5.1 モデル選択・基本設定

- 制御モデル（15種、§10）。回転数・流量・液面・温度・圧力で分類して表示する
- 制御名称（必須）
- 説明・メモ（任意）

### 5.2 PLC通信設定

- MVアドレス（読込、必須）
- PVアドレス（書込、必須）
- SPアドレス（読込、任意。使わない場合は内部SP）
- データ型：INT16 / UINT16 / INT32 / FLOAT32
- 読込/書込スケーリング（§5.3）

数値のアドレスはデバイス記号＋番号（MELSECは `D1000`、KEYENCEは `DM1000` など）。新規登録と複製では、通信方式に合わせて既存アドレスの次の10番台から2ワード間隔を提案する。FLOAT32・INT32は1点につき2ワードを使う。

FLOAT32は小数のRAW値を読み書きする。整数型は送信時に丸める。MVのON/OFFは、MELSECのM・YやKEYENCEのR・MRなどのビットデバイスと、`D1.0`・`DM1.0` などのワード内ビットに対応する。ワード内ビットは `.0`～`.15`（10進）または `.A`～`.F` で指定する。KEYENCEのXYM表記は対応する機種プロファイルを選ぶ。

### 5.3 レンジ定義

MV / PV / SP ごとに RAW 最小・最大、工業値 最小・最大、工業単位を設定する。PLC RAW値と工業値が異なる場合はスケーリングを行う。

MVの単位は、選択したモデルと入力方式に合わせて候補を絞る。

| モデル・入力方式 | 選べるMV単位 |
| --- | --- |
| モーター、流量・圧力のインバーターポンプ、液面の給水・排水ポンプ、圧力のコンプレッサ | %・Hz・rpm・V・mA |
| 電気ヒーター、チラー | %・V・mA・kW |
| 調節弁、給水弁、排水弁、蒸気加熱、冷却水弁、圧力の供給弁・排気弁 | %・V・mA |
| ON/OFF（リレー、全モデル共通） | %（OFF=0%、ON=100%） |

V・mAは機器への指令信号を表す。電源電圧・消費電力の計算には使わない。%以外は登録レンジの最小～最大を操作量0～100%へ換算し、%はそのまま使う。kWは加熱・冷却能力の指令値で、蒸気弁や冷却水弁の開度には指定できない。

例：PLC RAW 0～4000 ⇔ 工業値 0～100 %

確認ステップで次を検出する。

| 区分 | 内容 |
| --- | --- |
| 登録不可 | 名称・MV/PVアドレスの未入力、不正なレンジ・RAW値・単位、ON/OFF用アドレスの不正、同一対象のPV書込範囲とMV/SP読込範囲の重複 |
| 警告（確認チェックで登録可） | 対象間のPV書込範囲の重複、PV書込範囲と他対象のMV/SP読込範囲の重複、アドレス形式・使用範囲を確認できない場合、名称の重複 |

アドレスの重複は、FLOAT32・INT32の2ワード分とワード内ビットも含めて判定する。

## 6. 制御詳細画面

表示：

- 制御名称 / モデル / 計装タグ
- 現在状態、FORCE 表示、PLC通信状態
- SP / PV / MV（工業値・RAW値・レンジのバー、読込元／書込先アドレス）
- シミュレーション経過時間、PV書込先と書込状態

操作：

- 前の対象 / 次の対象（一覧順に切替、現在位置と総数を表示。先頭・末尾では該当方向を無効化し、選択タブを引き継ぐ）
- 制御開始 / 制御停止 / リセット
- モデル単体プレビュー（§20）
- 登録内容編集（停止中のみ）/ 複製
- タブ：トレンド / パラメータ / FORCE / 外乱 / 通信設定 / イベントログ
- 異常時：異常バナーと「異常リセット」

## 7. 制御開始・停止

演算スレッドが 100 ms 周期で動作する。制御中の対象は次の順で処理する。

1. PLCからMV取得
2. 必要ならSP取得
3. 工業値へ変換
4. プロセスモデル更新
5. PV計算
6. センサ特性（センサ遅れ）・ノイズ反映
7. PLC値へ変換（工業値レンジ外は最小／最大に制限）
8. PLCへPV書込み（NaN / Infinity は書き込まない）
9. トレンド記録

プレビュー中はPLCの代わりに仮MVを使ってモデルを演算し、PVは書き込まない。トレンドは停止中も記録する。GUI は演算スレッドとは別に 200 ms 周期で表示を更新する。

個別の制御開始にはPLC接続が必要。開始前に設定チェックを行い、通信異常中・レンジ不正は開始不可とする。PV書込アドレスの重複・FORCE中は確認を表示する。「全制御開始」は未接続なら接続完了を待ってから開始する（§21）。

停止時はモデル演算とPV自動書込みを停止する。停止時PVは「最終値保持」「初期値へ戻す」「指定値へ戻す」から選ぶ。制御中から停止し、通信が正常で「初期値」「指定値」を選んでいる場合は、その値を1回だけPLCへ書き込む。

## 8. トレンドグラフ

基本系列は SP / PV / MV。SP/PV を左軸（PVレンジ）、MV を右軸（登録したMVレンジ・単位）に表示する。

機能：

- 系列表示切替
- 時間軸変更（30秒 / 1分 / 2分 / 5分 / 10分 / 30分 / 60分 / 120分 / 240分）
- PV軸の表示範囲（レンジ固定 / 自動）
- 一時停止（記録は継続）。一時停止中はマウスで拡大・縮小・移動できる
- カーソル値確認（時刻・SP・PV・MV・外乱・FORCE）
- 履歴クリア
- FORCE中の区間を背景色で表示
- 保持時間は共通設定で1～240分、初期値30分（100 ms周期で全点）。変更時は最新の履歴を残す。設定をプロジェクトに保存する

## 9. 強制値（FORCE）

対象：

- MV FORCE：PLCから受信したMVの代わりに固定値を使う
- PV FORCE：PV書込先へ固定値を書き込む
- SP FORCE：SPの読込値の代わりに固定値を使う
- 外乱 FORCE：手動外乱・時間指定の外乱より優先する
- モデル固有入力 FORCE：モデルごとの入力（液面：排出弁開度、ヒーター：周囲温度、など）

FORCE中は、カード・詳細画面・画面上部の警告帯（件数と内容）・ステータスバーに表示する。個別解除、対象ごとの全解除、全FORCE解除を用意する。

## 10. プロセスモデル

全モデル共通で、むだ時間・センサ遅れ（一次遅れ）・ノイズ（標準PV幅に対する片側振幅%FS）を持つ。起動前のMVは0%とし、初回にもむだ時間を適用する。一次遅れは解析解で積分する。標準値は短時間のPID試験用で、特定の実設備を表す値ではない。ダミーPLCではモデルごとのPI定数と動作方向を使う。計算式と前提は [モデルの計算](models.md)、設備条件からの設定方法は [条件入力の計算](parameter-calculator.md) を参照。

| モデル | MV（標準単位） | PV（標準レンジ） | 初期PV | 標準SP |
| --- | --- | --- | --- | --- |
| モーター回転数 | インバータ出力 % | 回転数 0〜1800 rpm | 0 | 1200 |
| 流量（調節弁） | 弁開度 % | 流量 0〜50 m³/h | 0 | 30 |
| 流量（インバーターポンプ） | ポンプ回転数指令 % | 流量 0〜50 m³/h | 0 | 30 |
| 液面（給水弁） | 給水弁開度 % | 液面 0〜100 % | 50 | 60 |
| 液面（給水ポンプ） | ポンプ回転数指令 % | 液面 0〜100 % | 50 | 60 |
| 液面（排水ポンプ） | ポンプ回転数指令 % | 液面 0〜100 % | 50 | 60 |
| 液面（排水弁） | 排水弁開度 % | 液面 0〜100 % | 50 | 60 |
| 電気ヒーター | ヒーター出力 % | 温度 0〜200 ℃ | 25 | 80 |
| 蒸気加熱 | 蒸気弁開度 % | 温度 0〜200 ℃ | 25 | 90 |
| チラー | 冷却能力指令 % | 温度 0〜50 ℃ | 25 | 12 |
| 温度（冷却水弁） | 冷却水弁開度 % | 温度 0〜100 ℃ | 25 | 18 |
| 圧力（コンプレッサ） | コンプレッサ出力 % | ゲージ圧力 0〜500 kPa(g) | 0 | 300 |
| 圧力（供給弁） | 供給弁開度 % | ゲージ圧力 0〜600 kPa(g) | 200 | 300 |
| 圧力（排気弁） | 排気弁開度 % | ゲージ圧力 0〜600 kPa(g) | 200 | 300 |
| 圧力（インバーターポンプ） | ポンプ回転数指令 % | 吐出ゲージ圧力 0〜600 kPa(g) | 0 | 200 |

排水ポンプ・排水弁・チラー・冷却水弁・排気弁は、通常条件ではMV増加でPVが下がる。ダミーPLCはこの方向をモデルごとに持つ。PLC側のPID動作方向は使用する制御に合わせて設定する。冷却水がタンクより温かい場合は冷却水弁が加熱側に働く。

液面4モデルのPV・SPは%またはmmを選べる。`液位[mm] = 液位[%] × タンク高さ[mm] / 100`。mm設定でタンク高さを変更した場合は初期状態へ戻し、トレンド履歴と外乱予約をクリアする。

設備に応じたモデルの選び方は[制御パターン](control-patterns.md)を参照。全15種類で[条件入力ウィザード](parameter-calculator.md)を使用できる。

## 11. 外乱機能

PIDの外乱応答確認用。外乱量をスライダまたは数値で設定し、投入・解除する。

| モデル | 外乱 |
| --- | --- |
| 液面（給水弁・給水ポンプ） | 排出流量増加（m³/h） |
| 液面（排水ポンプ・排水弁） | 流入量増加（m³/h） |
| 電気ヒーター・蒸気加熱 | 熱負荷投入（kW） |
| チラー・冷却水弁 | 発熱量増加（kW） |
| モーター | 機械負荷増加（%） |
| 流量（調節弁） | 差圧低下（%） |
| 流量（インバーターポンプ） | 揚程能力低下（%） |
| 圧力（コンプレッサ・供給弁） | 消費流量増加（Nm³/h） |
| 圧力（排気弁） | 供給流量増加（Nm³/h） |
| 圧力（インバーターポンプ） | 100 kPa時の取出し流量増加（m³/h） |

手動投入・解除に加え、「今すぐ」「指定秒数後」のステップ投入と、任意の継続時間を指定できる。時間は対象の運転・プレビュー中の演算経過時間で進み、100 ms周期で反映する。停止・リセット・全制御停止で予約を取り消す。外乱FORCE中は強制値を優先し、予約の時刻は進む。外乱予約自体はプロジェクトへ保存しない。

## 12. モデルパラメータ設定

詳細画面のパラメータタブで、モデルごとの項目を編集する。

- 「停止中のみ」の項目は運転中は入力できない
- 「急変注意」の項目を運転中に変更すると確認を表示する（共通設定で確認をオフにできる）
- 変更はイベントログに記録する
- 停止中は「標準値に戻す」を実行できる
- 全15種類に「条件から計算」を用意する。基本条件と詳細条件を分け、現在値と計算結果を比較してから適用する。適用はモデルパラメータに限り、PLC側PID・レンジ・SP・初期PVを変更しない

## 13. 設定保存・読込

設備構成一式を「プロジェクト」（`*.psim`、UTF-8 の JSON）として保存・読込する。ファイルには `FormatVersion: 2` が必須。モデル種別などの列挙値は名前で保存し、形式・モデルパラメータ・レンジを検証して読み込む。

保存対象：

- 制御対象一覧
- PLCアドレス、データ型
- レンジ / スケーリング
- モデル種類・パラメータ
- 初期状態、停止時・通信異常時・復旧時の動作
- PLC接続設定（通信方式、機種、接続先、MELSECの接続先CPU、GX Simulator 3・KV STUDIOシミュレーターの使用、ModbusのUnit ID・ワード順・接続確認用アドレス）
- データ保存設定（CSV保存先、トレンド保持時間）
- 運転中のパラメータ変更を確認する設定

トレンド履歴・FORCE・外乱の状態、グラフ設定（時間軸・表示系列など）は保存しない。

`DEMO.psim` は上書きできない。DEMOを編集して保存するときは、別のファイル名を指定する。

新規作成・開く・終了のときは、制御中の対象があれば停止を確認し、未保存の変更があれば保存を確認する。

## 14. PLC通信

### 14.1 接続方式

| 方式 | 内容 |
| --- | --- |
| ダミーPLC | PLCなしで動作確認。PLC側のPI制御またはリレーON/OFF制御を模擬する |
| MELSEC PLC（SLMP） | MELSEC SLMP バイナリ 3E/4E、TCP / UDP。PLC機種は PlcComm.Slmp のプロファイルから選ぶ |
| KEYENCE PLC（Host Link） | KEYENCE KV Host Link、TCP / UDP。PLC機種は PlcComm.KvHostLink のプロファイルから選ぶ。標準ポート8501 |
| Modbus TCP | AMWD.Protocols.Modbus.Tcpを使うClient。TCPのみ、標準ポート502。Unit ID・32ビット値のワード順・接続確認用アドレスを設定する |
| GX Simulator 3 | SLMP で `127.0.0.1:5511`（TCP）に接続。iQ-R / iQ-L のみ。CPUパラメータ「RUN中の書込み許可/禁止設定：一括で許可する(SLMP)」が必要 |
| KV STUDIOシミュレーター | Host Linkで `127.0.0.1:8501`（TCP）に接続。KV-8000・KV-X500系列と各XYM表記に対応 |

MELSECの接続先CPUは自局・CPU 1～4・制御系CPU・待機系CPU・A系CPU・B系CPUから選ぶ。初期値は自局。接続テストと通常の読込・書込で同じ選択を使い、ステータスバーの接続先にも表示する。GX Simulator 3でも接続先CPUを選択できる。

Modbusのアドレスは `C0`（Coil）・`DI0`（Discrete Input）・`IR0`（Input Register）・`HR0`（Holding Register）のように領域と0起点の10進番号で指定する。各領域の番号は0～65535。数値MV・SPはIR/HR、ON/OFFのMVはC/DIまたはIR/HRのワード内ビット、数値PVはHRを使用する。32ビット値は連続する2レジスタを使い、上位ワードから／下位ワードからを選べる。Unit IDの設定範囲は0～255で、機器の指定値に合わせる。

設定の保存・プロジェクト読込だけでは接続せず、ツールバーの「接続」または「全制御開始」で接続する。接続方式を切り替えるときは、制御中・プレビュー中の対象をすべて停止してから切り替える。

### 14.2 通信周期と演算周期の分離

- モデル演算は全対象100 ms周期。通信周期は共通のPLC接続設定で指定する。
- 演算スレッドは PLC 通信を待たず、通信ループが保持している最新値を使う。
- 通信ループは通信周期ごとにMV・SPを読み込み、PVを書き込む。SLMPの数値はランダム読出し・書込みでまとめ、ON/OFFのMVは個別に読む。Host Linkはライブラリの型付き読込・書込みを使う。PVは値が変わったとき、および1秒ごとに書き込む。
- Modbusは領域に応じてFC01/02/03/04で読み、16ビットPVはFC06、32ビットPVはFC16で書く。各通信にタイムアウトを設定し、途中で中断した接続は破棄・再接続する。
- 読込結果は「正常」「初回取得待ち」「失敗」の3種類とし、初回取得待ちは異常にしない。応答が「タイムアウト＋通信周期×3」より古くなったら失敗とする。

### 14.3 状態

- 接続状態（ステータスバー）：ダミーPLC / 未接続 / 接続中 / 接続処理中 / 異常（理由を表示）。通信中に接続が途切れると自動で再接続する（1 秒から最大 30 秒の間隔）。「切断」で終了した場合は、次の接続操作まで再開しない。
- 対象ごとの通信状態：通信正常 / タイムアウト。

### 14.4 異常時動作

対象ごとに設定する。

- シミュレーション停止
- MV最終値保持
- MVを安全値へ変更
- PV書込み停止

通信復旧時の異常解除は自動または手動（「異常リセット」）を選べる。「シミュレーション停止」で停止した対象は、異常解除後に制御開始の操作が必要。プレビュー中に通信異常のリセットを要求した場合は、プレビュー終了後に通信を確認する。

PLCがエラー応答を返したアドレスは、その点だけを異常とし、他の対象の通信は続ける。SLMPの終了コード、Host Linkのエラーコード、Modbusの例外応答は、理由を画面に表示する。

## 15. 異常値・レンジチェック

監視対象：

- PLC通信値異常（終了コード）
- 通信タイムアウト
- NaN / Infinity（MV・PV）
- モデル演算異常（NaN / Infinity で停止）

異常は対象カード（赤枠・異常メッセージ）、詳細画面（異常バナー）、ステータスバー（件数）に表示する。

MVは登録レンジ内に制限する。PLCから読み込んだSPは、工業値への換算結果をそのまま使う。PVはPLCへ書き込むときにレンジの最小／最大に制限する。レンジ外だけでは異常表示しない。

## 16. イベントログ

記録内容：

- 登録・編集・削除、プロジェクトの新規・開く・保存
- 制御開始 / 停止、外乱投入 / 解除、モデル単体プレビュー
- 通信接続・切替・切断・復旧・再接続失敗
- FORCE ON/OFF
- パラメータ変更、異常時動作の変更
- リセット
- 異常発生 / 復旧
- CSV出力

日時、制御対象、種別、内容を記録する。詳細画面では種別で絞り込める。

## 17. 試験データ記録

保持中のトレンド履歴（設定により最大240分）を CSV にエクスポートする。

列：時刻、SP、PV、MV、外乱値、FORCE状態、通信状態（先頭行に対象名とアドレス）。文字コードは UTF-8（BOM付き、Excel でそのまま開ける）。保存先の初期値は共通設定の CSV 保存先。

## 18. 初期状態・リセット

登録内容で初期PV・初期SPを設定する。例：液面 50 %、温度 25 ℃、モーター停止、圧力 0 kPa。

リセットはPVを初期値に戻し、モデル内部状態と経過時間をリセットして外乱予約を取り消す。SP・FORCE・手動外乱・トレンド履歴は保持する。

プロジェクトを開くと、全対象を停止状態で初期PV・初期SPから読み込む。PLCからSPを読み込む設定では、制御開始後の読込値を使う。


## 19. 接続テスト

登録・編集・複製の画面（PLC通信設定ステップ）から実行する。実機PLCが未接続の場合は、選択した通信方式でテストのために一時接続する。

- 読込テスト：MV・SP を1点ずつ直接読み、RAW値・工業値・応答時間を表示する（PLCへは書き込まない）
- PV書込テスト：書込先アドレスを示した確認チェックを入れたときだけ実行でき、実行後もチェックを保持して繰り返しテストできる

共通設定の接続テストは、一時的に接続してPLCの応答を確認する。SLMPではSD0（自己診断エラーコード）、Host Linkでは運転モード（`?M`）を読む。Modbusでは設定した接続確認用アドレスを1点読み、ビットはBIT、レジスタはUINT16として扱う。PLCへ値は書き込まない。

## 20. モデル単体プレビュー

PLCと接続せず、GUIから仮MVを入力してモデル応答を確認するモード。連続値MVはスライダー、ON/OFF（リレー）MVはOFF（0%）／ON（100%）の選択で操作する。プレビュー開始時も登録されたMV方式に合わせ、ON/OFFでは仮MVに中間値を使わない。診断用のMV FORCEが有効な場合は、仮MVより強制値を優先する。PVはPLCへ書き込まない。停止中の対象でのみ開始でき、モデルパラメータ調整とPLC PID調整を分離できる。

## 21. 一括操作

メイン画面から以下を実行できる。

- 全制御開始（開始する対象と、異常中で開始しない対象を確認してから実行。未接続なら接続し、成功してから開始。接続失敗時は開始しない）
- 全制御停止（確認なしで即時実行。ツールバー右端に常時表示）
- 全異常リセット（異常中の対象だけに解除を要求。通信異常は応答確認後に解除し、その他の異常は表示を解除する。原因が続く場合は再検出する。PV・経過時間・FORCE・履歴と運転状態を保持する）
- 全FORCE解除（ツールバーと警告帯）

## 22. 制御対象複製

既存制御対象の設定を引き継いで登録ウィザードを開く。名称に「のコピー」を付け、PLCアドレスは空いている番台を提案する。

## 24. 動作確認

自動テストでモデルの物理収支・応答・条件計算、通信異常、FORCE、入力検証、保存・読込を確認する。通信はテスト用PLCサーバでSLMP（TCP）・Host Link（TCP/UDP）・Modbus TCPの読込・書込、型変換、再接続、点単位の異常分離とモデル運転を確認する。

GX Simulator 3（iQ-R）と実機PLC（SLMP）では接続・読込・書込と運転を確認済み。KV STUDIOシミュレーターおよびKEYENCE実機PLCとのHost Link通信も確認済み。

Modbus TCPの検証にはテスト用Serverを使用する。ETH-MODBUS-IO8R-Aの実機通信は未確認。
