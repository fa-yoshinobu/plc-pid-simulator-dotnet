# 使い方

## 新しいプロジェクトで試験する

### 1. 通信設定を保存する

`PidSimulator.exe` を起動すると、制御対象が未登録の新規プロジェクトを表示します。初期画面の「① 通信設定」、または「設定 → PLC接続設定」を開きます。

| 試験する環境 | 選ぶ設定 |
| --- | --- |
| PLCなしで試す | 「ダミーPLC」。PLC側のPIDもアプリ内で模擬します |
| MELSEC PLCのPIDを試す | 「MELSEC PLC（SLMP）」。[実機PLCの設定](#実機plcの設定)を参照してください |
| KEYENCE PLCのPIDを試す | 「KEYENCE PLC（Host Link）」。[KEYENCE PLCの設定](#keyence-plcの設定)を参照してください |
| GX Works3のシミュレーションで試す | 「MELSEC PLC（SLMP）」で「GX Simulator 3 に接続」を選びます。[GX Simulator 3の設定](#gx-simulator-3の設定)を参照してください |
| KV STUDIOのシミュレーションで試す | 「KEYENCE PLC（Host Link）」でシミュレーター接続を選びます。[KV STUDIOシミュレーターの設定](#kv-studioシミュレーターの設定)を参照してください |

設定を保存しただけでは通信は始まりません。接続テストは未接続でも一時的に接続して実行し、終了後に切断します。ダミーPLCでは接続操作は不要です。

### 2. 制御対象を登録する

「＋ 制御対象を登録」を押し、6ステップで設定します。

| ステップ | 設定する内容 |
| --- | --- |
| モデル選択 | 回転数・流量・液面・温度・圧力の15種類から、操作する機器に合わせて選びます。[制御パターンの選び方](control-patterns.md)を参照してください |
| 基本設定 | 制御対象の名称と説明。名称の先頭に `LIC-101` などの計装タグを付けると、一覧カードのタグ表示に使います |
| レンジ設定 | MV・PV・SPのRAW値と工業値の対応、単位、連続値／ON/OFFのMV方式 |
| PLC通信設定 | MV・SPの読込アドレス、PVの書込アドレス、データ型。読込テスト・PV書込テストで値と換算結果を確認できます |
| 初期値・停止時・異常時の動作 | 初期PV・SP、停止時のPV、通信異常時・復旧時の動作 |
| 確認 | 登録内容と設定チェックの結果。警告がある場合は、内容を確認してチェックを入れます |

制御中は、ここで指定したPVアドレスへ計算結果を書き込みます。PV書込テストも同じアドレスへ書き込むため、画面に表示された書込先を確認して実行します。

モデル演算は全対象100 ms、通信は「PLC接続設定」の共通の通信周期で動作します。

#### レンジと単位

RAWはPLCで扱う値、工業値は画面やモデルで扱う値です。例えば `RAW 0～4000 ⇔ 工業値 0～100 %` と設定すると、PLCから読んだ2000は50%になります。

`FLOAT32` では小数のRAW値をそのまま読み書きできます。`FLOAT32`・`INT32`は1点につき2ワード使うため、MV・PV・SPは `D1000 / D1002 / D1004`（MELSEC）、`DM1000 / DM1002 / DM1004`（KEYENCE）のように間隔を空けます。

MV単位はモデルに合う候補から選びます。%以外は登録したMVレンジの最小～最大をモデルの操作量0～100%に換算します。例えば0～60 Hzなら30 Hzは50%です。モデルの最大回転数や能力はパラメータで別に設定します。液面のPV・SPは%またはmmです。対応単位と換算の詳細は[レンジ定義](specification.md#53-レンジ定義)を参照してください。

#### ON/OFF（リレー）のMV

「レンジ設定」でON/OFFを選び、「PLC通信設定」でMVに `M100`、`Y1A`、`D1.0`（MELSEC）、`R100`、`MR100`、`DM1.0`（KEYENCE）などを指定します。OFFを0%、ONを100%としてモデルに入力し、PV・SPは数値データで扱います。KEYENCEのXYM表記を使う場合は、通信設定で対応するXYM機種を選びます。

ワード内ビットは `.0`～`.15`（10進）と `.A`～`.F`（10～15）に対応します。ダミーPLCではON/OFF制御も模擬できます。リレーのON/OFF信号を想定しており、SSRの高速パルス・デューティ制御は扱いません。

### 3. 設備条件からモデルパラメータを設定する

登録した対象の詳細画面で「パラメータ → 条件から計算」を開きます。全15モデルで使用でき、停止中に適用します。

1. モデルに合う用途を選びます。
2. 水量・温度・時間などの基本条件を入力します。放熱やセンサ応答などは「詳細条件」で調整できます。
3. 現在値と計算結果を比較して適用します。

例えば、加熱ならタンクの水量と昇温時間、液面ならタンクの容量または内径・高さ、モーターなら応答時間または慣性・モーター出力から設定できます。各モデルの入力条件と計算の前提は[設備条件からのパラメータ計算](parameter-calculator.md)を参照してください。

適用するのはモデルパラメータです。PLC側のPIDゲイン、レンジ、初期PV・SPは別に設定します。入力条件と登録済み設定の違いは結果画面で確認できます。

### 4. 制御を開始する

「全制御開始」を押します。実機PLC・PLCシミュレーターが未接続なら自動で接続し、接続完了後に制御を始めます。接続できない場合は理由を表示します。「接続」で先に通信を開始し、対象の詳細画面から個別に開始することもできます。

一覧のカードを開くと、トレンド・パラメータ・FORCE・外乱・通信設定・イベントログを確認できます。詳細画面の「前の対象」「次の対象」で、一覧の順に対象を切り替えられます。現在位置を「2 / 15」のように表示し、選択中のタブは引き継ぎます。先頭では前、末尾では次のボタンが無効になります。「一覧へ戻る」で対象一覧へ戻ります。

対象ごとの「制御停止」または「全制御停止」でモデルの演算を止めます。制御中から停止したときのPVは登録設定に従い、「初期値へ戻す」「指定値へ戻す」では、通信正常時にその値を1回PLCへ書き込みます。「切断」は制御を停止して通信を終了します。

排水・冷却・排気などは、MVを上げるとPVが下がるモデルです。ダミーPLCはモデルに合わせて動作方向を切り替えます。外部PLCのPIDはPLC側で動作方向を設定してください。

### 5. プロジェクトを保存する

「ファイル → 名前を付けて保存」で `*.psim` ファイルへ保存します。次の試験では「ファイル → プロジェクトを開く」から読み込みます。

保存するのは、対象一覧、モデルとパラメータ、PLCアドレス・データ型、レンジ、初期状態、停止時・通信異常時・復旧時の動作、PLC接続設定、CSV保存先・トレンド保持時間、運転中のパラメータ変更確認の設定です。読み込むと各対象は初期状態・停止状態になります。

トレンド履歴・FORCE・外乱やその予約、グラフの表示設定は保存しません。試験結果を残すときはCSVへ出力してください。

## DEMOを試す

`PidSimulator.exe` と同じフォルダに `DEMO.psim` を置き、「ファイル → DEMOを開く」を選びます。15種類のモデルを1件ずつ停止状態で読み込みます。「全制御開始」でダミーPLCによる試験を開始できます。

DEMOには、Hz指令の慣性モーターと、mm表示・FLOAT32の給水ポンプ液面も含まれます。

`DEMO.psim` は上書きできません。変更後に保存すると「名前を付けて保存」が開くので、別の名前で保存してください。別名で保存したプロジェクトは通常どおり上書きできます。

## 実機PLCの設定

PLC側のパラメータ設定は、以下のサイトを参考にしてください。通信ライブラリの設定ガイドと、本アプリと同じ通信ライブラリを使用するPLC Consoleの設定例です。

- [PLC Communication Libraries — PLC設定ガイド](https://plc-comm-docs-site.fa-labo.com/plc-setup/)
- [FA Labo PLC Console — 接続設定例](https://plc-console.fa-labo.com/plc/plc-side-settings.html)

「設定 → PLC接続設定」で「MELSEC PLC（SLMP）」または「KEYENCE PLC（Host Link）」を選び、接続するCPUの機種、IPアドレス、ポート、TCP/UDP、タイムアウト、通信周期を入力します。PLC側も選択した通信方式を有効にしてください。

MELSECでは「接続先CPU」で、自局・CPU 1～4・制御系CPU・待機系CPU・A系CPU・B系CPUを選べます。初期値は自局です。選択したCPUを接続テスト、MV・SPの読込み、PVの書込みに使い、プロジェクトにも保存します。

「接続テスト」で応答を確認して保存し、登録へ進みます。対象ごとのアドレスは登録画面で確認します。接続設定を切り替えるときは、運転中の対象を停止してから変更します。

画面下のステータスバーに接続状態を表示します。通信中に接続が途切れると自動で再接続します。「切断」で終了した通信は、次に接続操作をするまで再開しません。

対象ごとの「復旧時」が「自動再開」なら応答を確認して通信異常を解除し、「手動再開」なら詳細画面の「異常リセット」で解除します。ツールバーの「全異常リセット」では、異常中の対象をまとめて解除できます。通信異常は応答を確認してから解除し、プレビュー中の通信確認はプレビュー終了後に行います。

異常リセットはPV・経過時間・FORCE・トレンド履歴を保持します。原因が残っている異常は再検出されます。「シミュレーション停止」で停止した対象は、異常解除後に「制御開始」を押してください。

## GX Simulator 3の設定

GX Works3のiQ-R / iQ-Lプロジェクトで、CPUパラメータ「RUN中の書込み許可/禁止設定」を**一括で許可する(SLMP)**に設定します。英語版の表示は `Enable/Disable Online Change: Enable All (SLMP)` です。

1. パラメータを設定し、GX Works3のシミュレーションを開始します。
2. このアプリの「設定 → PLC接続設定」で「MELSEC PLC（SLMP）」を選びます。
3. PLC機種を **MELSEC iQ-R (built-in)** または **MELSEC iQ-L (built-in)** にします。
4. 「GX Simulator 3 に接続」にチェックを入れます。
5. 「接続テスト」で確認して保存します。

チェック中の接続先は次の値に固定されます。チェックを外すと、入力していた実機のIPアドレス・ポートに戻ります。

| 項目 | 値 |
| --- | --- |
| IPアドレス | `127.0.0.1` |
| ポート | `5511` |
| 通信方式 | TCP |

読込はできるのに書込みで**終了コード0x0055**が出る場合は、パラメータをシミュレータへ書き込み、CPUをリセットしてRUNにしてください。

## KEYENCE PLCの設定

「設定 → PLC接続設定」で「KEYENCE PLC（Host Link）」を選び、PLCの機種とHost Linkの接続先を設定します。ポートの初期値は `8501` です。TCP/UDPとポートはPLC側の設定に合わせてください。

機種はKV-NANO・KV-3000・KV-5000・KV-7000・KV-8000・KV-X500の各系列から選びます。KV-8000AはKV-8000系列、KV-X310/X500/X520/X530/X550はKV-X500系列を選びます。XYM表記を使う場合は、同じ系列の「XYM」を選びます。「接続テスト」は運転モードを読み、応答を確認します。

MV・PV・SPの数値は `DM1000 / DM1002 / DM1004` などに割り当てます。XYM表記では `D1000 / D1002 / D1004` とします。データ型は別欄で選び、アドレスに型の接尾辞は付けません。`.F` はワード内ビット15の指定として扱います。リレーの `R`・`MR`・`LR`・`CR` は下2桁が `00`～`15` の表記です（例：`MR115` の次は `MR200`）。XYM表記のリレーには `X`・`Y`・`M` などを使います。

## KV STUDIOシミュレーターの設定

1. KV STUDIOでシミュレーションを開始します。
2. 「設定 → PLC接続設定」で「KEYENCE PLC（Host Link）」を選びます。
3. PLCの機種に合わせてKV-8000系列またはKV-X500系列を選びます。XYM表記の場合は対応する「XYM」を選びます。
4. KV STUDIOシミュレーターへの接続にチェックを入れ、「接続テスト」で確認して保存します。

チェック中は `127.0.0.1:8501`（TCP）に固定します。チェックを外すと、入力していた実機の接続先に戻ります。

## 応答を調べる

### モデル単体プレビュー

停止中に「モデル単体プレビュー」を使うと、画面から仮のMVを入力してモデルの応答を確認できます。連続値MVはスライダー、リレーMVはOFF／ONで操作します。プレビュー中はPVをPLCへ書き込みません。

### リセット

「リセット」でモデルを初期PVへ戻し、経過時間を0にして外乱予約を取り消します。SP、FORCE、手動外乱、トレンド履歴は保持します。

### トレンドとCSV

トレンドはSP・PVを左軸、MVを右軸に登録した単位で表示します。表示を一時停止すると、記録を続けたまま拡大・移動し、カーソルで値を確認できます。

「設定 → データ保存」でトレンド保持時間を1～240分に設定します。初期値は30分です。保持中の履歴は「ファイル → 試験データをCSVエクスポート」から保存できます。

### FORCEと外乱

「FORCE」ではMV・PV・SP・外乱などを指定値に固定します。運転中のPV FORCEはPLCへ書き込むPVにも反映されます。「全FORCE解除」でまとめて解除できます。

「外乱」では値を指定して投入・解除できます。「ステップ・時間指定外乱」では今すぐ、または指定秒数後の投入と継続時間を指定します。予約時間は対象の運転・プレビュー中だけ進み、停止・リセットで予約を取り消します。外乱FORCE中は強制値を優先します。
