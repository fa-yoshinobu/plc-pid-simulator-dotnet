# 時刻と通信キャッシュ

演算時間とPCの実時刻を分ける。モデル・ダミーPLC・外乱予定に渡す時間は従来どおり1周期0.1秒で進め、スリープ中の演算を追いかけない。イベントログの記録時刻には、その時点のPCのローカル時刻を使用する。

トレンドとCSVは `SimulationEngine.ToTime(T)` で実時刻へ変換する。実行開始時、周期間隔が予定より1秒を超えて遅れたとき、または予測した表示時刻とPC時刻に1周期（0.1秒）を超える差が生じたとき、次のサンプル時刻とその時点のPC時刻の対応を記録する。その点以降に新しい対応を使い、過去のサンプル・外乱開始時刻のラベルを書き換えない。イベントログとCSVで同じローカル時刻を使用する。時計を戻した場合、記録される実時刻も戻る。

グラフ上の位置・表示範囲・カーソル検索は演算時間の順序を維持し、横軸のラベルとカーソルの時刻だけを実時刻へ変換する。これにより時計を戻しても範囲が逆転せず、正しいサンプルを選べる。スリープ中にサンプルを生成しないため、その区間は横軸ラベルの時刻が飛ぶ形で表す。

周期間隔が予定より1秒を超えて遅れた場合は、超過した秒数を「演算が N 秒中断しました」とイベントログへ1件記録する。復帰直後のサンプルは復帰後のPC時刻に対応し、PVなどのモデル状態は通常の1周期分だけ進む。PCの時計変更だけでは中断イベントを出さない。

通信キャッシュの読取鮮度、初回読取待ち、異常点の再試行、書込値の再送、未使用点の破棄は `TimeProvider.GetTimestamp()` と `GetElapsedTime()` で判定する。時計合わせで時刻が進んだり戻ったりしても、これらの経過時間は変わらない。既存の鮮度上限、再試行2秒、再送1秒、未使用5秒の設定は変更しない。接続待ち・通信周期の所要時間も従来どおり単調増加する時間で計測する。

`SimulationEngine` と `CachedPlcClient` の時計は `TimeProvider` で差し替えられる。自動テストでは実機通信やPCの時計変更をせず、60秒の中断・時計の1時間前進/後退を模擬して、モデルの同一ステップ、過去ラベル、CSVとイベント時刻、中断1件、通信鮮度・再試行・未使用の判定を確認する。
