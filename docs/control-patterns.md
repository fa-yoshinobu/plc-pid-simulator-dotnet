# 制御パターンの選び方

モデルは「何を測るか」と「何を動かすか」で選ぶ。全15種類に条件入力ウィザードとDEMOを用意する。以下の方向は通常の使用条件での関係。

| 分類 | モデル | 操作するもの | MVを上げたとき |
| --- | --- | --- | --- |
| 回転数 | モーター | 回転数指令 | 回転数が上がる |
| 流量 | 調節弁 | 弁開度 | 流量が増える |
| 流量 | インバーターポンプ | ポンプ回転数指令 | 流量が増える |
| 液面 | 給水弁 | 給水弁開度 | 液位が上がる |
| 液面 | 給水ポンプ | 給水ポンプ回転数指令 | 液位が上がる |
| 液面 | 排水弁 | 排水弁開度 | 液位が下がる |
| 液面 | 排水ポンプ | 排水ポンプ回転数指令 | 液位が下がる |
| 温度 | 電気ヒーター | 加熱能力 | 温度が上がる |
| 温度 | 蒸気加熱 | 蒸気弁開度 | 温度が上がる |
| 温度 | チラー | 冷却能力 | 温度が下がる |
| 温度 | 冷却水弁 | 冷却水弁開度 | 温度が下がる |
| 圧力 | コンプレッサ | 空気供給量の指令 | 圧力が上がる |
| 圧力 | 供給弁 | 空気の供給弁開度 | 圧力が上がる |
| 圧力 | 排気弁 | 空気の排気弁開度 | 圧力が下がる |
| 圧力 | インバーターポンプ | 水ポンプ回転数指令 | 圧力が上がる |

ダミーPLCは各モデルの方向に合わせ、連続値MVではPI制御、ON/OFF MVではヒステリシス付きのリレー制御を模擬する。実際のPLCの制御方向はPLC側で設定する。

## 設備に合わせた選び分け

- **モーター**：回転数そのものをPVにする場合に選ぶ。応答時間を合わせる「時定数・加減速」と、回転体の重さやモーター能力を使う「慣性・トルク」の計算方式がある。
- **流量**：弁を操作する場合と、遠心ポンプの回転数を操作する場合で選び分ける。ポンプでは高低差や背圧により、低速で流れなくなる条件も設定できる。
- **液面**：給水側と排水側のどちらを操作するか、弁かポンプかで選ぶ。PV・SPは%またはmm。タンクは一定断面積とし、容量と高さ、または内径と高さを使う。
- **加熱**：電気ヒーターは加熱能力を操作する。蒸気加熱はジャケット・コイルでの間接加熱で、蒸気温度に近づくほど加熱量が減る。
- **冷却**：チラーは冷却能力を指令し、冷却水弁はコイル・ジャケットの水量を操作する。冷却水弁では入口水温と流量が冷却量に影響する。
- **圧力**：空気タンクはコンプレッサ・供給弁・排気弁から選ぶ。一定圧力の空気源から入れるなら供給弁を使う。水ポンプの吐出圧を試す場合はインバーターポンプを使う。

## MVの単位

モデルが操作する機器に合わせ、登録画面で選択できる単位が変わる。V・mAはアナログ指令信号を表す。

| 対象 | 選択できる単位 |
| --- | --- |
| モーター、各ポンプ、コンプレッサ | %、Hz、rpm、V、mA |
| 電気ヒーター、チラー | %、kW、V、mA |
| 各弁 | %、V、mA |
| ON/OFF（リレー）MV | %（OFFは0%、ONは100%） |

%以外のMVは、登録した工業値レンジの最小を0%、最大を100%として換算する。例えば0～60 Hzでは30 Hzが50%になる。%入力は数値をそのまま使う。プレビュー、FORCE、グラフ、PLCとの換算は登録した単位で扱う。

モデルの最大回転数・流量・加熱能力などを、MVレンジ最大時の設備能力に合わせる。Hzは入力レンジの換算であり、モーターの極数や滑りから回転数を求めるものではない。

各モデルの式と前提は[モデルの計算](models.md)、入力条件と換算例は[条件入力ウィザード](parameter-calculator.md)を参照。
