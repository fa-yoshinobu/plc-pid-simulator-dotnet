# 設備条件からのパラメータ計算

詳細画面の「パラメータ → 条件から計算」で、現在選択しているモデルに合う用途を選び、設備条件を入力する。水量・温度・時間などの基本条件を先に表示し、容器重量・周囲温度・応答時間などは折りたたんだ詳細条件にまとめる。分からない詳細条件は初期値から始められる。

現在値と計算値を比較してから適用する。キャンセルでは変更しない。適用は停止中に限り、ログへ記録し、プロジェクト保存の対象とする。入力値と計算結果の両方をモデルの設定範囲で検証する。

## 加熱・冷却

水を完全混合とし、密度を1 kg/L、比熱を4.19 kJ/(kg·℃)、ステンレスの比熱を0.5 kJ/(kg·℃)と近似する。熱容量は `C = 水量[L] × 4.19 + 容器重量[kg] × 0.5`。

目標温度での熱移動量から `H = 熱移動[W] / 1000 / |目標−周囲|` を求める。熱の向きは温度差から決まり、周囲より低温なら熱が入る。目標温度と周囲温度が同じ場合、熱移動量は0 Wとする。

電気ヒーターは `C dT/dt = Q − H(T−周囲)` の解析解から指定時間で指定温度になるQを求める。放熱なしなら `Q = C × 温度差 / 時間[秒]`。チラーは同じ熱収支でQの符号を反転し、機器・ポンプなどから常時入る熱を加算して必要冷却能力を求める。常時熱負荷、冷却装置の応答時間、最低到達温度は詳細条件で指定する。最低到達温度未満の目標は受け付けない。

時間は全出力での応答開始後の時間。むだ時間・センサ遅れ・冷却装置の応答を含まない。PIDが出力を絞る場合は、入力した時間と一致しない。完全混合、一定熱容量の範囲で扱い、沸騰・凍結・蒸発・連続入替えは再現しない。

水の熱量計算の参考：[Spirax Sarco](https://www.spiraxsteam.com/learn-about-steam/steam-engineering-principles-and-heat-transfer/steam-consumption-of-heat-exchangers/)。ステンレスの比熱はシミュレーション用の概算値。

### 蒸気ジャケット・コイル

蒸気温度 `Ts` と水温 `T` の差を使い、伝熱量を `UA × max(Ts−T, 0)` とする。UAは伝熱係数と面積をまとめた値で、単位はkW/℃。基本条件に蒸気温度を入力し、UAは指定した昇温時間から計算する。蒸気温度は目標温度より高くする。

全開時の熱収支 `C dT/dt = UA(Ts−T) − H(T−周囲)` の解析解に対し、指定時間後に目標温度となるUAを二分探索する。供給能力上限 `pmax = UA × (Ts−開始温度)` を同時に設定する。計算対象の単調昇温中はこの上限を超えず、水温の上昇につれて伝わる熱が減る。

計算では弁特性をイコールパーセント、不感帯を1%、通常の熱負荷を0に設定する。運転時の加熱量と近似の範囲は[加熱・冷却のモデル](models.md#加熱冷却)を参照。

例：30 L、容器10 kg、25→80℃、10分、蒸気120℃、目標時放熱500 Wなら、熱容量130.7 kJ/℃、UA約0.19385 kW/℃、供給能力上限約18.42 kWとなる。80℃時の伝熱量は約7.75 kW。

間接蒸気加熱の温度差と伝熱面積の関係：[Spirax Sarco — Heating with Coils and Jackets](https://www.spiraxsarco.com/learn-about-steam/steam-engineering-principles-and-heat-transfer/heating-with-coils-and-jackets)。

## モーター

応答時間から試したい場合は「インバーター駆動のポンプ・ファン」を選ぶ。最大加減速を `最高回転数 / 加減速上限での到達時間`、時定数を `95%応答時間 / 2.996` とし、負荷0の簡易応答を設定する。両方の制限が同時に働くため、実際の到達時間はさらに長くなる。

回転体の重さによる応答差を試す場合は、次のどちらかを選ぶ。

- **慣性モーメントとモーター能力から設定**：モーター軸に換算した合計慣性J、最高回転数、モーター出力を入力する。
- **円盤・フライホイールの慣性から設定**：均一な中実円盤の重量mと直径から `J円盤 = m r² / 2` を求め、モーター自身の慣性を加える。rの単位はm。減速機などがある場合は、軸換算済みのJを入力する方式を使う。

最高回転数から角速度を `ωmax = rpm × π / 30` とし、最大トルクを `出力[kW] × 1000 / ωmax` で求める。詳細条件では通常の負荷、粘性抵抗による損失、最大トルクに達する速度偏差を指定する。損失がWで与えられた場合の粘性抵抗係数は `b = 損失 / ωmax²`。通常負荷と粘性抵抗がモーター能力以上になる条件は受け付けない。

運転時の式と近似の範囲は[モーターの計算方式](models.md#モーターの計算方式)を参照。

## 液面タンクの寸法と単位

給水弁・給水ポンプ・排水弁・排水ポンプの4モデルで、満水容量と高さ、または内径と高さから設定できる。

- 容量から：`断面積[m²] = 満水容量[L] / 高さ[mm]`。モデルの内径は0にし、計算した断面積を使う。
- 内径から：縦置き円筒タンクとして `断面積[m²] = π × (内径[mm] / 2000)²`。内径が0より大きい間は、この断面積を優先する。

満水容量は `断面積[m²] × 高さ[mm]` L。一定断面積のタンクを想定し、横置き円筒や円すい底のように高さで断面積が変わる形状は扱わない。

PV・SPの単位は登録画面で%またはmmを選ぶ。モデル内部の液位%を `液位[mm] = 液位[%] × タンク高さ[mm] / 100` で換算する。ウィザードは単位を変更しない。mm表示中に高さを変更すると初期状態へ戻るため、初期PV・SP・レンジも確認する。

| 温度（冷却水弁） | 水量・温度・時間から必要な有効伝熱係数Kを求め、冷却水の熱容量流量Wから `UA=−W ln(1−K/W)` へ逆算。KがW以上なら流量または時間の変更が必要 |

応答時間が時定数の項目は、変化の約63%までの時間を指す。約3倍で95%に達する。ウィザード内で95%到達時間を直接尋ねる項目は、時定数に換算して適用する。

圧力は大気圧を0とするゲージ圧。空気タンク内の温度は詳細条件で指定し、初期値は20℃。供給弁と排気弁の能力を指定する圧力条件は[空気タンクの圧力](models.md#空気タンクの圧力)を参照。

## 適用する情報

全15種類で同じ「用途選択 → 基本・詳細条件 → 比較して適用」の流れを使う。

MVにHzなどの単位を使う場合は、登録した工業値レンジの最小～最大をモデル入力の0～100%へ換算する。例えば0～60 Hzなら30 Hzが50%に相当する。%入力はその数値を使う。ウィザードが計算する最高回転数・最大能力は、モデル入力100%での値である。

計算結果一覧のモデルパラメータのみ変更する。ノイズなど一覧にない項目、レンジ、初期PV、SP、PLC側のPIDゲインは変更しない。温度条件と登録済み初期PV・SPの相違、レンジ外の値、モーター・流量の到達範囲との相違は計算結果画面に表示する。PLCからSPを読む場合はPLC側の設定を確認する。初期PVを編集したときはリセット後に試す。

モデルの方向とMV単位の選び方は[制御パターン](control-patterns.md)、運転時の式と前提は[モデルの計算](models.md)を参照。
